# Working in this repository

- This is a standalone repository within the wider `indrayam.com` site. Follow the parent `../AGENTS.md` for the shared site nav, favicon, footer, and cross-site work.
- `asked-about.json` is generated by a bot and is the data contract with `app.js`. Do not hand-edit its content; if the schema changes, update `app.js` and the field list in `README.md`.
- The page must never display the bot's private fields (`source_page`, `subtitle`, `footer`, `ref`); the public copy lives in `index.html`.
- Keep the site static and dependency-free. `app.js` loads the JSON with `fetch`, so preview with a local static server, not `file://`.
- For layout or styling changes, inspect the page at desktop and phone widths before claiming it works.
- Vercel (Git-connected, project `sightings`) is the canonical host.
